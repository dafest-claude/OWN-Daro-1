# Constructibilidad

Estructura de trabajo para el análisis de Constructibilidad.

## Carpetas

- **`datos_entrada/`**: Datos de entrada / insumos del análisis (archivos fuente: PDF, Excel, etc.).
- **`analisis_generados/`**: Análisis generados a partir de los datos de entrada (resultados, scripts y reportes).

> Misma estructura de insumos → resultados que se viene usando en el resto del proyecto.
